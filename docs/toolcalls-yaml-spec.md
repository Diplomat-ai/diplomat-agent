# toolcalls.yaml specification v1.0

This document defines the format of `toolcalls.yaml`, the behavioral inventory generated by diplomat-agent.

## Overview

`toolcalls.yaml` is a machine-readable, diffable registry of every tool call with real-world side effects in a Python AI agent codebase. It records what each function can do, what governance checks exist, and what checks are missing.

## Format

### Metadata (required)

```yaml
generated: "2026-04-09T14:30:00Z"     # ISO 8601 UTC timestamp
version: "0.3.0"                       # diplomat-agent version that generated the file
spec_version: "1.0"                    # format version
path: "./my-agent"                     # scanned directory path
```

### Summary (required)

```yaml
summary:
  total: 47                            # total tool calls with side effects
  no_checks: 31                        # zero governance checks detected
  partial_checks: 12                   # some checks but not all expected ones
  confirmed: 4                         # acknowledged via # checked:ok annotation
```

### Tool calls (required)

Tool calls are grouped into three sections, in order:

1. **NO CHECKS** — functions with side effects and zero governance checks
2. **PARTIAL CHECKS** — functions with some checks but missing others
3. **CONFIRMED** — functions acknowledged via `# checked:ok` annotation

#### NO CHECKS section

Ordered by severity within the section:
1. payment / database_delete / dynamic_code (highest impact)
2. llm_call / agent_invocation
3. database_write / http_write
4. email / messaging / publish / file_delete

```yaml
tool_calls:

  # ⚠ NO CHECKS — payment
  - function: process_refund
    file: agents/payment.py
    line: 42
    actions:
      - stripe.Refund.create(amount=amount)
    checks: []
    missing:
      - no bounds on amount
      - no rate limit
    owasp: [ASI-02, ASI-03, ASI-06]
```

#### PARTIAL CHECKS section

```yaml
  # ~ PARTIAL CHECKS
  - function: update_record
    file: api/routes.py
    line: 88
    actions:
      - session.commit()
    checks:
      - type: auth_check
        code: "Depends(get_current_user)"
    missing:
      - no input validation on record_id
    owasp: [ASI-01, ASI-02]
```

#### CONFIRMED section

```yaml
  # ✓ CONFIRMED
  - function: send_alert
    file: agents/notify.py
    line: 15
    actions:
      - requests.post(ALERT_URL, json=msg)
    checks:
      - type: rate_limit
        code: "@rate_limit(10, period=60)"
    missing: []
    confirmed: "protected by API gateway"
    owasp: []
```

## Field reference

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `function` | string | Yes | Function name |
| `file` | string | Yes | Relative file path |
| `line` | integer | Yes | Line number of function definition |
| `actions` | list[string] | Yes | Code excerpts of detected side effects |
| `checks` | list[object] | Yes | Detected governance checks (empty list if none) |
| `checks[].type` | string | Yes | One of: `input_validation`, `rate_limit`, `auth_check`, `approval_step`, `idempotency_key`, `retry_bound`, `confirmation` |
| `checks[].code` | string | Yes | Source code excerpt of the check |
| `missing` | list[string] | Yes | Human-readable hints for missing governance |
| `owasp` | list[string] | Yes | OWASP Agentic Top 10 codes (ASI-01 through ASI-10) |
| `confirmed` | string | CONFIRMED only | Reason from `# checked:ok — [reason]` annotation |

## Design rules

- **`actions[]` strings do not include line numbers.** This ensures diff stability when code is reformatted or moved.
- **Mirror mode:** The file is fully regenerated on each scan. It is not merged with previous versions.
- **`spec_version`** enables future format evolution without breaking parsers.

## Excluded fields (with rationale)

| Field | Status | Rationale |
|-------|--------|-----------|
| `owner` | Deferred to v2 | `git blame` is sufficient for now |
| `reviewed` / `reviewed_at` | Deferred to v2 | Adds maintenance burden |
| `resolve` | Excluded | Pollutes diffs |
| Line numbers in `actions[]` / `checks[]` | Excluded | Breaks diff stability |

## Generate

```bash
diplomat-agent . --format registry --output-registry toolcalls.yaml
```
